# FuckBrains

**FuckBrains** — это динамичный 3D-шутер от первого лица с элементами roguelike, разработанный на игровом движке **Godot 4.7**. Погрузитесь в мрачную атмосферу подземелий, сражайтесь с врагами, собирайте уникальные предметы и выживайте как можно дольше.

---

## 🎮 Особенности игры

### Геймплей
- **Динамичные бои**: Уничтожайте врагов с помощью разнообразного оружия (пистолет, винтовка, дробовик) и способностей.
- **Процедурная генерация уровней**: Каждый проход уникален благодаря системе процедурной генерации комнат и коридоров.
- **Система здоровья и маны**: Управляйте ресурсами игрока, используя аптечки и другие предметы.
- **Экономика**: Зарабатывайте деньги, продавайте найденные предметы и покупайте улучшения в магазине.
- **Перманентные улучшения**: Разблокируйте постоянные бонусы между забегами (мета-прогрессия).

### Предметы
В игре представлено более **20 уникальных предметов**, которые можно подобрать и использовать:
- **Боевые**: Детское масло (Baby Oil), Яйца Чингиса (Chingis Eggs), Одеколон (Cologne)
- **Лечебные**: Медполис (Medpolis), Хуй Йогурт (Huy Yogurt)
- **Ценные**: Золотая цепь (Gold Chain), Фото MGE (MGE Photo), Дневник (Diary)
- **Разные**: Лампочка (Lightbulb), Гвозди (Nails), Вантуз (Plunger), Кубик Рубика (Rubik's Cube), Припой (Soldering Iron), Геймпады (PS/Xbox) и другие

### Враги
- **Обычные враги**: Преследуют игрока, атакуют в ближнем бою
- **Дальние враги**: Атакуют на расстоянии
- **Боссы**: Уникальные противники с особыми способностями (например, Boss Monstro)

### Визуальные эффекты
- **VHS-фильтр**: Стилизованное пост-обработка в стиле ретро-видеокассет с настраиваемой интенсивностью
- **Кровь и эффекты**: Система декалей крови, брызг и луж
- **Освещение**: Динамическое освещение с использованием WorldEnvironment

### Ключевые системы

#### 1. Глобальная система (Global.gd)
Управляет состоянием игры:
- Здоровье, мана, выносливость игрока
- Боезапас (пистолет, винтовка, дробовик)
- Деньги и инвентарь
- Статистика (критический урон, шанс крита, скорость и т.д.)
- Множители урона, скорости, удачи
- Специальные эффекты (черви, десинхронизация, шипы)

#### 2. Игрок (player.gd)
- Управление движением (ходьба, бег, прыжки, скольжение)
- Система выносливости
- Стрельба и отдача
- Камера с эффектами наклона и покачивания
- Mantling (преодоление препятствий)

#### 3. Генератор уровней (level_generator.gd)
- Процедурная генерация комнат и коридоров
- Размещение врагов, предметов и декораций
- Навигационная система для ИИ

#### 4. Враги (enemy.gd, ranged_enemy.gd, boss_monstro.gd)
- Конечный автомат состояний (IDLE, CHASE, ATTACK, DEAD и др.)
- Поиск пути через NavigationAgent3D
- Различные типы атак (ближняя, дальняя, рывок)

#### 5. Предметы (item_*.gd)
- Интерактивные предметы с анимацией парения
- Система подсветки при наведении
- Механика покупки/подбора

#### 6. VHS Пост-обработка (vhs_filter.gd, vhs_horror.gdshader)
- Эффект старой видеокассеты
- Настраиваемая интенсивность, шум, RGB-смещение
- Режим записи (REC индикатор)

## 🎯 Как играть

### Управление
- **WASD** — Перемещение
- **Пробел** — Прыжок
- **Shift** — Бег / Скольжение
- **ЛКМ** — Стрельба / Атака
- **ПКМ** — Прицеливание
- **R** — Перезарядка
- **E** — Взаимодействие с предметами
- **Tab** — Инвентарь / Меню улучшений

### Цель игры
Выживайте как можно дольше в процедурно генерируемых подземельях, уничтожая врагов, собирая ценные предметы и покупая улучшения. Игра заканчивается, когда здоровье игрока упадет до нуля.

## 🚀 Запуск проекта

### Требования
- **Godot Engine 4.7** (или совместимая версия 4.x)
- **Видеокарта** с поддержкой Vulkan (для рендерера Forward Plus)

### Установка
1. Клонируйте репозиторий:
   ```bash
   git clone <repository-url>
   cd FuckBrains
   ```

2. Откройте проект в Godot Engine:
   - Запустите Godot 4.7
   - Нажмите "Import" и выберите файл `project.godot`
   - Дождитесь импорта ресурсов

3. Запустите игру:
   - Нажмите кнопку Play (F5) в редакторе Godot
   - Основная сцена: `res://Scenes/main_menu.tscn` (или автозапуск через настройки проекта)

## ⚙️ Настройки

Игра поддерживает настройку следующих параметров:
- **Графика**: Интенсивность VHS-эффекта, шум, RGB-смещение

- **Управление**: Чувствительность мыши, инверсия осей
- **Звук**: Громкость музыки и эффектов

Настройки доступны через главное меню или консоль разработчика.
